# 💖 Valentine's Webpage

## 📌 Description

This project is a fun and interactive Valentine's webpage built with **HTML, CSS, and JavaScript**.  
It features a multi-screen experience with playful animations, custom styling, and interactive buttons to create a personalized Valentine's-themed message.

The webpage includes:

- An intro screen with a romantic message
- A question screen asking _“¿quieres ser mi San Valentín?”_
- A playful **Yes / No** interaction where the **No** button moves around and shrinks while the **Yes** button grows
- A final screen with a love message, photos, a GIF, and animated hearts and stars

## 📂 Structure

| File         | Type       | Purpose                                                                                     |
| ------------ | ---------- | ------------------------------------------------------------------------------------------- |
| `index.html` | HTML       | Main structure of the Valentine's webpage, including the intro, question, and final screens |
| `style.css`  | CSS        | Styling, layout, gradients, animations, button design, and floating effects                 |
| `script.js`  | JavaScript | Handles screen transitions, button interactions, and floating hearts/stars animations       |
| `foto1.jpg`  | Image      | Main image shown on the question screen                                                     |
| `foto2.jpg`  | Image      | Image displayed on the final screen                                                         |
| `gato.gif`   | GIF        | Decorative/funny GIF shown on the final screen                                              |

## ▶️ How to Run

### Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run it with **Live Server** or open it directly in your browser.

### Using Browser

1. Make sure all project files are in the same folder.
2. Double-click `index.html`.
